# ASTRA Local Chat

Fast local conversational model for BetGPT and ASTRA chat workloads.

- Alias: qwen-chat-local
- API: OpenAI-compatible `/v1/chat/completions`
- Health: `/health`
- Intended network: Railway private networking only
